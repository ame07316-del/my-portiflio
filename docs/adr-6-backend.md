# ADR — برومبت 6: معمارية الخلفية والـ API

## المقارنة (حكم واقعي لبورتفوليو بمالك واحد)

| المعيار | CMS مُدار (Sanity/Strapi Cloud) | لوحة مخصصة كاملة | **هجين بسيط (المختار)** |
|---|---|---|---|
| تحكم بالمحتوى ثنائي اللغة | جيد | كامل | كامل |
| تكلفة شهرية | $0–99 | استضافة فقط | استضافة فقط |
| صيانة وتحديثات | على المزوّد | عليك بالكامل | ~400 سطر مُدارة ذاتيًا |
| أمان المصادقة | على المزوّد (جيد) | تبنيها بنفسك (خطر لو ضعفت) | session موقّعة + تحقق على السيرفر |
| اعتماد على طرف خارجي | **نقطة فشل خارجية** | لا | لا |
| ملاءمة مهارة المالك | متوسطة | عالية | **عالية** |

**التوصية:** هجين بسيط = **مخزن JSON ذرّي + API صغير بلغة المنصة (node:http بلا اعتماديات) + لوحة مخصصة**.
السبب: مالك واحد، محتوى محدود، لا أحمال متوقعة، والرغبة في التحكم الكامل بالعربي/الإنجليزي وحالات النشر —
وهو ما تفشل فيه القوالب المجانية أو تزيد فيه تكلفة الـ CMS عن حاجته.

## Topology نصي

```
[متصفح زائر] ──GET /api/public/content──▶ [server] ──▶ مخزن JSON (نشر فقط)
[متصفح عمرو] ──POST /api/login──────────▶ [server] ──▶ جلسة موقّعة (cookie httpOnly)
             ──PUT/POST /api/admin/*────▶ [server] ──▶ تحقق جلسة + CSRF + Validation
                                                    ──▶ نسخة (snapshot) ──▶ سجل تغييرات
                                                    ──▶ كتابة ذرّية (tmp+rename)
```

## حدود النظام
- **عام:** قراءة محتوى منشور فقط. لا كتابة. لا أسرار.
- **إدارة:** كل عملية كتابة. الصلاحية تُفرض **على السيرفر في كل طلب** — الواجهة مجرد راحة استخدام.
- **مصادقة:** مالك واحد، لا تسجيل عام. كلمة سر تُشتق بـ scrypt؛ جلسة HMAC موقّعة؛ SameSite=Lax؛ CSRF double-submit.
- **وسائط:** رفع base64 بحد 2MB، فحص magic bytes (png/jpg/webp فقط)، اسم مولّد، ومسح قبل الحذف إن مستخدمة.

## عقود مفاهيمية (الغرض · الفاعل · الصلاحية · التحقق · الأخطاء)

| العملية | الفاعل | التحقق | أخطاء |
|---|---|---|---|
| `POST /api/login` | عام | طول كلمة السر ≤ 200 | 401 خطأ بيانات دخول |
| `GET /api/public/content` | عام | — | 500 مخزن تالف → نسخة احتياطية |
| `PUT /api/admin/projects/:id` | عمرو | جلسة + CSRF + enum/status/url/order | 400 حقل ناقص · 401 · 403 · 409 |
| `POST /api/admin/projects/:id/publish` | عمرو | **يمنع نشر in_progress كمكتمل** + تحذير ترجمة ناقصة | 409 قاعدة نشر |
| `POST /api/admin/projects/:id/restore` | عمرو | وجود النسخة | 404 |
| `DELETE /api/admin/media/:name` | عمرو | فحص الاستخدام | 409 مستخدمة في: […] |

## قرارات مفتوحة (تتوقف على استضافة لاحقة)
نطاق دائم؟ مزوّد بريد لنموذج تواصل؟ نقل المخزن لقاعدة حقيقية عند تعدد الأجهزة؟
كلها **غير مطلوبة الآن** — المخزن JSON يكفي لمالك واحد على خادم واحد.
