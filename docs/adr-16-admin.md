# ADR — برومبت 16: لوحة الإدارة الشاملة

## خريطة الشاشات

```
دخول (مستخدم واحد، لا تسجيل عام)
 └─ الملخص: عدّادات الحالات · تحذيرات الحقول الناقصة · آخر التعديلات
     ├─ المشاريع: قائمة بحالات وشارات ونقص → محرر ثنائي اللغة (AR/EN tabs)
     │    ├─ حقول: عنوان/وصف/دور/ملاحظة لكل لغة · حالة · نوع · ترتيب · تقنيات · روابط · صور+نص بديل
     │    ├─ حفظ مسودة · نشر · إلغاء نشر · أرشفة · حذف (بنسخة قبله)
     │    └─ نسخ قابلة للاستعادة (آخر 12) — الاستعادة تحفظ الحالة الحالية أولًا
     ├─ الأقسام: ظهور + ترتيب أقسام الرئيسية
     ├─ الوسائط: رفع (png/jpg/webp ≤2MB بفحص magic bytes) · حذف مرفوض لو مستخدمة (409)
     ├─ الإعدادات: SEO ثنائي اللغة · تواصل · مظهر ضمن خيارين فقط
     └─ السجل: كل فعل بكائن ووقت وفاعل
```

## مصفوفة الصلاحيات

| العملية | زائر | عمرو (جلسة صالحة) | بدون CSRF |
|---|---|---|---|
| قراءة محتوى منشور | ✅ | ✅ | — |
| قراءة مسودات (`?drafts=1`) | ❌ 401 | ✅ | — |
| أي كتابة | ❌ 401 | ✅ | ❌ 403 |
| نشر مشروع in_progress | ❌ |  **409 قاعدة** | ❌ |
| نشر بترجمة ناقصة | ❌ | ⚠️ فقط بتأكيد صريح ثانٍ | ❌ |
| حذف وسائط مستخدمة | ❌ |  409 بقائمة الاستخدام | ❌ |

**القاعدة المعمارية:** الواجهة مجرد راحة؛ **كل** صلاحية وتحقق يُفرض في `server.js`. إخفاء `/admin.html` ليس حماية.

## تدفقات رئيسية
1. **تعديل → معاينة → نشر:** حفظ مسودة → «معاينة بالمسودات» (جلسة) → نشر → فحص الموقع المنشور.
2. **تراجع:** أي حفظ/نشر/حذف ينشئ نسخة → استعادة بأي وقت؛ الحذف لا يمحو النسخ.
3. **انقطاع شبكة أثناء الحفظ:** الواجهة تعرض خطأ الحالة ولا تفقد نموذج المحرر (لا يُعاد تحميل الصفحة).

## معايير قبول
- دخول خاطئ → 401 بدون تسريب وجود الحساب. جلسة منتهية → 401 والواجهة ترجع لشاشة الدخول.
- مستخدم غير مخول لا يرى أي محتوى مسودة حتى بطلب مباشر للـ API.
- لا تظهر أسرار أو متغيرات بيئة في أي استجابة أو في الواجهة.
- كل نشر مسبوق بمعاينة؛ لا نشر لترجمة ناقصة بدون تحذير مؤكد.

## مخاطر مقبولة وحدود
- مخزن JSON على خادم واحد: كافٍ لمالك واحد؛ الانتقال لقاعدة حقيقية قرار لاحق (ADR-6).
- كلمة السر الأولية تُكتب في `data/credentials.txt` (خارج git) أو تُمرر كـ `ADMIN_PASSWORD`.
- لا MFA إجباري الآن؛ يُفعّل إن وفّره مزوّد الاستضافة لاحقًا.
