# ADR — برومبت 10: رحلات المستخدم والحالات الطرفية

## تدفق الزائر
```
وصول → Hero (مجسم .glb + اسم) → [تبديل لغة؟ SSR meta تتطابق] → شريط المهارات
→ العجلة: سكرول/سحب/أسهم(عند التركيز)/فهرس → بطاقة نشطة
   → معاينة خارجية | مستودع | دراسة حالة (Dialog) → إغلاق → متابعة
→ تواصل: mailto | wa.me | GitHub
[تقليل حركة أو موبايل؟] → قائمة ثابتة بنفس الروابط والمحتوى
```

## تدفق المالك
```
دخول (كلمة سر) → جلسة httpOnly + CSRF
→ ملخص (تحذيرات نقص) → محرر (تبويبات AR/EN) → حفظ مسودة (نسخة تلقائية)
→ معاينة /?drafts=1 بجلسة → نشر (قواعد: in_progress مرفوض · ترجمة ناقصة بتأكيد ثانٍ)
→ ندم؟ استعادة نسخة (الحالية تُنسخ أولًا) → سجل يوثّق كل فعل
```

## مصفوفة الحالات الطرفية (البداية · القرار · الأثر المرئي · التعافي)

| الحالة | القرار | الأثر المرئي | التعافي |
|---|---|---|---|
| زائر/كتابة بدون جلسة | 401 من السيرفر | لا شيء للزائر؛ للمالك شاشة دخول | دخول صحيح |
| **جلسة منتهية أثناء العمل** | 401 عام في `api()` | رجوع فوري لشاشة الدخول + «انتهت الجلسة» | إعادة دخول، لا بيانات ضائعة سيرفرًا |
| CSRF ناقص/خاطئ | 403 | رسالة حالة في اللوحة | الواجهة ترسل التوكن تلقائيًا |
| **انقطاع شبكة أثناء حفظ** | فشل fetch | «⚠ الشبكة مقطوعة» + النموذج لا يُصفَّر | مؤشر «الشبكة رجعت» وإعادة الحفظ |
| صورة معطوبة في كارت | `onerror="this.remove()"` | الكارت يبقى نصيًا نظيفًا | لا شيء مطلوب |
| WebGL غير متاح/فشل تحميل .glb | catch في hero3d | رسالة «المحتوى شغال بدون المجسم» وإخفاء Canvas | الموقع كامل بدون المجسم |
| فشل `/api/public/content` | catch في syncContent | الكروت المكتوبة في HTML تستمر | لا إدراك للخطأ أصلًا |
| أعمال = صفر | emptyCheck | حالة فارغة بنص واضح بدل أسطوانة خاوية | نشر من اللوحة |
| بيانات ناقصة في مسودة | `_missing` من السيرفر | عدّاد نقص في المحرر وتحذيرات الملخص | استكمال ثم نشر |
| نشر مشروع in_progress | 409 قاعدة | رسالة صريحة، لا تجاوز | تغيير الحالة أولًا |
| ترجمة ناقصة عند النشر | 409 + قائمة | Dialog يؤكد ثانيًا بوعي | تأكيد صريح أو استكمال |
| حذف صورة مستخدمة | 409 + usedBy | رفض بقائمة المواضع | إزالة الاستخدام أولًا |
| تقليل الحركة مفعّل | REDUCED + CSS | كل شيء ثابت ومقروء، العجلة قائمة | — |
| رابط خارجي مكسور | لا يُكتشف محليًا (الساندبوكس معزول) | — | **فحص روابط في الإنتاج** قرار موثّق مؤجل |

## ما لا نفعله (بوعي)
- لا مزامنة موزعة/Outbox/IndexedDB: مالك واحد، لا تبرير حقيقي (برومبت 12 يفصّل).
- لا افتراض أحمال أو Kubernetes: الموقع شخصي.
- لا إخفاء محتوى جوهري خلف hover: كل رابط وزر ظاهر دائمًا؛ الـ hover تجميل فقط.
