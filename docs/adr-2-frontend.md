# ADR — برومبت 2: معمارية الواجهة الأمامية

## القرار: static-first + vanilla modules + API صغير
قورن بثلاث خيارات لواجهة موقع شخصي بمالك واحد:

| الخيار | الحكم |
|---|---|
| React/Next SPA للواجهة العامة | **مرفوض الآن**: المحتوى شبه ثابت، وSPA تضيف bundle وتعقيد وتحرمنا من قراءة المحتوى بدون JS — وهي قاعدة جودة عندنا |
| SSG/_framework مع hydration | مرفوض لنفس السبب + لا حاجة لـ state معقد |
| **HTML حقيقي + وحدات vanilla + مزامنة من API** | **المختار**: المحتوى مقروء بدون JS، والحركة إضافة لا شرط، واللوحة منفصلة تمامًا |

تطبيقًا لقاعدة الملف: **لم تُضف أي مكتبة بلا حاجة مثبتة** — Lenis وScrollTrigger مبررتان في ADR-4 (سكرول متصل + choreography)، وThree.js مبررة هنا بالمجسم `.glb`. لا Zustand/TanStack/Framer Motion.

## مسؤوليات الوحدات (كما هي منفذة)

| الوحدة | المسؤولية | لا تفعل |
|---|---|---|
| `index.html` | هيكل المحتوى + البديل الكامل بدون JS/-API | منطق |
| `main.js` | i18n، الحركة، العجلة، مزامنة `/api/public/content`، كشف الكلمات | WebGL، إدارة |
| `hero3d.js` | مشهد Three.js وتحميل `.glb` وتفاعل Hold | محتوى نصي |
| `case.js` | دراسات الحالة (حقائق موثقة + تحذير الناقص) | تعديل بيانات |
| `admin.html/js` | واجهة المالك فقط | أي صلاحية (كلها في server.js) |
| `server.js` | السلطة: مصادقة، CSRF، تحقق، نشر، نسخ، وسائط، **SEO SSR** | عرض بصري |

## نموذج المحتوى والترجمة
- الحقول الثنائية `{ar,en}` في كل كيان (ADR-7). الواجهة تقرأ `data-ar/data-en` للنصوص الثابتة، و`title/desc/…` للمحتوى الديناميكي.
- **SEO عربي/إنجليزي يُحقن على السيرفر** (`renderIndex`): `<title>` و`description` و`og:*` و`lang/dir` حسب `?lang=` ثم cookie ثم Accept-Language، والعربية افتراضي. الـ cookie يضبطه `main.js` عند التبديل فيتطابق SSR مع اختيار الزائر.
- قاعدة حركة: الكشف **كلمة-بكلمة** في العربية؛ `letter-spacing: 0` قسري؛ المنطقي properties لعكس RTL.

## Tokens والشبكة
الألوان والخطوط من موجز الهوية حرفيًا في `:root` (CSS)؛ شبكة 12/8/4 عبر breakpoints عند 1024/860/640؛ إيقاع 8pt في متغيرات `--s*`.

## الحماية والتخزين والتحقق والنشر
لا تُكرر هنا: السلطات والعقود في ADR-6، وقواعد النشر والنسخ في ADR-7، وشاشات المالك في ADR-16.
**الواجهة لا تحمل سرًا واحدًا**: لا مفاتيح، ولا منطق صلاحية، ولا تحقق يُعتمد عليه客户端.

## أسئلة مفتوحة (لا تعطل التنفيذ)
نطاق دائم و`hreflang`/مسارات `/en/`؟ استضافة نهائية تحدد مصير المخزن؟ مصادر صور المشاريع والنص البديل؟ كلها مؤجلة بقرار موثّق لا بنسيان.
